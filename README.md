# Sum Calculator

## Overview

Sum Calculator is a simple web application that allows users to enter two numbers and calculate their sum instantly. The project demonstrates basic JavaScript functionality, DOM manipulation, event handling, and responsive UI design using Bootstrap.

## Features

* Accepts two numeric inputs from the user.
* Calculates the sum of the entered numbers.
* Displays the result instantly on the webpage.
* Simple and responsive user interface.
* Built using HTML, CSS (Bootstrap), and JavaScript.

## Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* JavaScript

## Project Structure

├── index.html
└── README.md

## How It Works

1. Enter the first number.
2. Enter the second number.
3. Click the **Calculate Sum** button.
4. The application calculates and displays the result instantly.

## Learning Objectives

This project demonstrates:

* HTML form elements and input handling
* JavaScript functions
* DOM manipulation using `getElementById()`
* Type conversion using `Number()`
* Event handling with button clicks
* Responsive design using Bootstrap

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter two numbers and calculate their sum.
